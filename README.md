# My-Compiler

## Overview
My-Compiler is a simple compiler developed using **C#**. It supports a limited set of keywords and control-flow statements, providing a basic implementation of the compiler construction process.

## Supported Keywords
The compiler currently recognizes the following keywords:

- `ints`
- `floats`
- `ifs`
- `whiles`
- `do whiles`

**Note:** The `fors` construct is still under development and has not yet been fully implemented.

## Compilation Process
The compiler processes source code through **five stages of compilation** and generates **Assembly code** as its output.

This project aims to demonstrate the fundamental concepts of compiler construction, from processing source code to generating low-level instructions.

## Technologies Used
- **Programming Language:** C#
- **Output:** Assembly code
